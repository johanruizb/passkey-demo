# Commit conventions

## Why

- No changelog exists and none is configured.
- Commit subjects follow the single existing commit: Conventional Commits in Spanish, imperative, lowercase after the type.

## Gotchas

- `public/app.js` is generated by `pnpm build` and ignored; never stage it.
- Tests run with `node --test` via `pnpm test`.
- Pushing to `main` deploys `public/` to GitHub Pages.
